### 🌟 Featured Projects

#### 📡 Distributed Systems & Real-Time Backends

- **[Quix Messenger](https://github.com/vladdjuga/quix-messenger)**
  - *Full-stack event-driven chat platform.*
  - **Stack**: `.NET 10`, `Next.js 15 (React 19)`, `SignalR`, `MassTransit`, `RabbitMQ`, `Redis`, `PostgreSQL 16`, `Docker`.
  - **Highlights**: Modular monolith with event-driven message dispatching, horizontal scaling via Redis SignalR backplane, sub-millisecond presence cache, hybrid JWT (HttpOnly refresh cookies), and BFF API proxying.

- **[mqonnor (Arbiter)](https://github.com/vladdjuga/mqonnor)**
  - *Clean Architecture event ingestion, routing, and persistence broker.*
  - **Stack**: `.NET 10`, `ASP.NET Core`, `MongoDB`, `System.Threading.Channels`, `SignalR`.
  - **Highlights**: High-throughput bounded in-process event bus with natural backpressure, custom DI Mediator, Result pattern error modeling, swappable bus interfaces, and embedded MongoDB containerization.

- **[Anonymous Real-Time Chat](https://github.com/vladdjuga/real-time-chat)**
  - *Omegle-style anonymous pairing service with zero database overhead.*
  - **Stack**: `Go 1.24`, `Gin`, `WebSockets`, `MVC Architecture`.
  - **Highlights**: Pure in-memory concurrency model using thread-safe matching queues and mutexes, WebSocket message routing, and automated deployment configs for Render & Railway.

#### ⚡ Systems, Networking & Embedded Firmware

- **[STM32F429 Discovery Real-Time System](https://github.com/vladdjuga/stm32-freertos-system)**
  - *Multi-tasking embedded control system on ARM Cortex-M4.*
  - **Stack**: `Embedded C`, `FreeRTOS`, `STM32 HAL`, `CMSIS`.
  - **Highlights**: 4 prioritized concurrent tasks, phase-accurate 40 kHz DAC sine wave generation modulated via 10 Hz ADC potentiometer readings, and message-queue-driven flicker-free LCD rendering.

  - **Stack**: `C++20`, `Standalone Asio`, `CMake`, `Ninja`, `spdlog`, `Google Test`.
  - **Highlights**: Custom binary wire framing protocol (64-bit size header + payload stream), decoupled listener and sender sockets, cross-platform build support with WinSock integration.

- **[STM32 Music Player & Fireworks Engine](https://github.com/vladdjuga/stm32-music-fireworks)**
  - *Interactive tone synthesizer and LCD particle physics animation.*
  - **Stack**: `Embedded C`, `STM32 HAL`, `DMA2D`, `LTDC`, `SDRAM`.
  - **Highlights**: Hardware Timer 3 PWM tone synthesis across 6 classical pieces, 100-particle physics explosion engine updated on Timer 4 interrupts, and DMA2D hardware-accelerated framebuffer blitting.
